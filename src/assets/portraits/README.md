# Agent headshot

Put the owner's licensed JPG, PNG, WebP, or AVIF headshot here, then set
`portraitUrl` to `src/assets/portraits/headshot.jpg` (using the actual filename).
The build creates responsive WebP images, records the actual dimensions, and
uses the generated URL in the agent's structured data. Keep the original here
so future builds in the owner's repository work independently.

Existing `/images/...` paths in `public/` and remote image URLs remain supported
and are served directly. Optimize those files yourself, or use this directory
for automatic processing. Do not include private documents or unlicensed photos.
